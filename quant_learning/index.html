SMALL CAPITAL EDGE

小资金的优势，不是免费的 Alpha

西蒙斯式的数据、算力、算法竞争并非个人的正确起点。个人更适合寻找容量较小、持仓周期较长、能用公开数据研究的机会，但这些只是潜在优势，不是收益保证。

01容量与灵活性：小资金对市场冲击可能更低，能研究大型机构容量受限的细分机会；但小众市场常伴随差数据、低流动性和更高执行风险。
02时间自主权：没有基金赎回和月度排名压力，不代表可以无限期扛回撤；资金期限、机会成本和风险预算仍然约束你。
03AI 的真实作用：降低编程、信息整理和实验自动化成本，不会自动创造独家数据、统计优势或交易纪律。
START THIS WEEK

别等学完再开始

第一周先建立最小研究环境，并选一条自己熟悉的中低频想法做基线实验。

01建一个可复现的 Python 研究仓库。
02获取一份日线数据，计算收益、波动率、回撤和交易成本。
03读《Quantitative Trading》新版目录与核心章节，写下自己的交易系统地图。
04把第一个策略想法写成可证伪假设，不急着追求漂亮回测。
建议并行
课程和书籍按研究用途分为必修主线与选修拓展。必修表示建议优先掌握，不意味着每本书都必须逐页读完；具体市场数据、平台功能、证书和云算力可能另有费用或访问条件。

WHAT SUCCESS MEANS

课程毕业，不等于盈利毕业。

课程验收看你能否解释、复现、测试和审计；Alpha 候选看它是否有经济机制、无数据泄漏、通过样本外和成本检验；前向与实盘表现则需要足够长的独立证据。任何课程、模型或 AI Agent 都不能保证达到世界顶级水平或特定收益。
